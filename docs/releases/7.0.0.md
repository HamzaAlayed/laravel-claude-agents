# Laravel Guild 7.0.0

## What’s new

Planned specialist work now has kernel-enforced runtime budgets. Every lane
snapshots limits for elapsed seconds, tool calls, turns, tokens, and estimated
US dollars when its delivery is planned.

- Claude Code meters each planned specialist tool call before execution and
  records a complete usage receipt after synchronous Agent/Task completion.
- `guild budget list` shows the limit, cumulative usage, and breach state for
  every lane.
- `guild budget record` lets another runtime submit the same five-dimensional
  receipt before reporting a stage result.
- A breach persists as `budget_exceeded`, appears as `⛔` on the delivery
  board, and stops automatic dispatch until a human chooses a new plan.

The contract, command examples, pricing policy, and recovery boundaries are in
[Runtime stage budgets](../runtime-budgets.md).

## Breaking changes

A stage claimed through the Guild kernel must now record all five usage
dimensions before `guild report` accepts its result:

- elapsed seconds
- tool calls
- turns
- tokens
- US-dollar cost

Claude Code supplies this receipt automatically for synchronous Agent/Task
work. Third-party and direct kernel integrations must add equivalent metering
or run `guild budget record` before reporting. Do not invent unavailable
telemetry: the lane must stop instead.

Asynchronous subagents do not expose a complete completion receipt to the
hook. Use synchronous dispatch for kernel-planned lanes. `guild ready` also
adds an effective `budget` object to each returned stage.

## Compatibility

Existing `kernel.json` files load safely: missing budgets receive the shared
defaults, missing usage receives zero values, and a legacy already-running
stage without the new claim timestamp may still report. New claims use the
receipt requirement.

Claude Code has identity-aware automatic enforcement. Gemini receives the
same planning contract and uses the explicit CLI receipt path because its hook
payload cannot identify a Guild specialist reliably. Codex Core does not ship
Guild subagents.

Estimated cost is a conservative guardrail, not an invoice. Exact runtime
cost wins when supplied. The versioned rate table deliberately keeps Sonnet at
an upper bound above its current public price and uses an expensive fallback
for unknown models.

## Verification

- Kernel units cover budget validation, default snapshots, hard ceilings,
  elapsed-time and tool-call prechecks, cumulative usage, and terminal breach
  behavior.
- CLI tests cover budget inspection and complete usage receipts.
- Hook integration tests prove event idempotency, automatic five-dimensional
  recording, over-budget blocking, and fail-closed missing telemetry.
- The full kernel, console, eval, guardrail, generated-target, manifest, shell,
  and frontend release gates pass before the tag is published.
