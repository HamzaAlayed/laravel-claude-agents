# Laravel Guild 8.7.0

## What’s new

All pipeline entry points now inherit one canonical orchestration contract.
The nine pipeline commands and a directly invoked delivery coordinator retain
inline runtime instructions, but those ten copies are generated from one
reviewed source instead of evolving independently.

- `config/orchestration-contract.md` owns the shared lifecycle prose.
- `scripts/sync-orchestration-contract.py` writes or checks every carrier.
- Seven focused unit tests cover exact synchronization, repair, idempotence,
  structural corruption, legacy migration, and carrier-set drift.
- Hosted CI checks both the generated artifacts and the synchronization tool.

See the [canonical orchestration contract](../orchestration-contract.md) for
the ownership boundary and maintenance runbook.

## Breaking changes

There are no runtime behavior changes for installed users. Maintainers must no
longer edit the generated Interface lifecycle block inside a command or the
delivery coordinator. Edit the canonical source and regenerate all carriers.

## Fixes

- Pipeline commands and direct coordinator sessions can no longer silently
  disagree about checkpoints, loop detection, retries, feedback routing, or
  interruption recovery.
- Partial or hand-edited copies fail CI with the exact stale carrier path.
- Missing, unexpected, duplicate, or malformed carriers fail closed instead of
  shrinking the synchronized surface unnoticed.

## Compatibility

Claude, Cursor, Gemini, Codex, and classic installs still receive complete
inline orchestration instructions; no runtime include mechanism is required.
Command-specific and coordinator-specific behavior remains outside the
generated block and is unchanged.

## Verification

- Seven orchestration synchronization unit tests pass.
- The full shell guardrail suite passes with the new source/carrier and CI
  ratchets.
- Coordinator hash, inventory, frontmatter, manifest, body-budget, kernel,
  console, eval, release, UI, and distribution-generation gates pass.
- GitHub-hosted CI validates every required job for the exact release commit.
