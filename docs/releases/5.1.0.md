# Laravel Guild 5.1.0

## What’s new

Laravel Guild now has one explicit shared harness and a validated policy
profile for every one of its 18 agents. The registry records each role’s
mutation scope, approval categories, and allowed handoffs, while the shared
layer defines lifecycle states, budgets, protected actions, verification, and
the six-field result contract.

The console also enforces a default 120-turn loop ceiling, alongside its time,
tool-call, token, and dollar budgets. A caller may lower the ceiling per run but
cannot raise it above the release-owned hard limit.

## Compatibility

This is a backward-compatible feature release. Existing commands, agent names,
hooks, and stage-return files continue to work. Runs that submit a custom budget
may now include `max_turns`; omitted values receive the shared default.

## Verification

- The harness validator checks all 18 profiles against canonical frontmatter.
- Console tests cover turn-budget interruption and evidence emission.
- Existing guardrail, kernel, generated-target, inventory, and manifest checks
  remain release gates.
