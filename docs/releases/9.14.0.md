# Laravel Guild 9.14.0

Production performance and security checklists

## What’s new

- Run the 80-check production performance checklist from the
  `laravel-deploy` skill. It covers reproducible baselines, provisional
  budgets, rollback triggers, and 10 ranked first actions.
- Run the 112-control production security checklist from the
  `laravel-security` skill. It includes ASVS 5.0.0 and OWASP Top 10:2025
  references, a go-live gate with evidence and owners, and 10 ranked
  quick wins.
- The frontend, performance, and security agents now reference these
  checklists for production audits.

## Breaking changes

None.

## Fixes

- Frontend and performance audits report initial list rendering independently
  of API payload size.
- Felix keeps the private-media blocker open until paired CDN evidence shows
  that the authorized user gets the attachment and the anonymous request is
  denied. The security guide separates planned key rotation from suspected
  compromise response.

## Compatibility

The checklists ship in the Claude Code, Gemini, and Codex skill packages.
They state reference runtime versions and identify controls that depend on
the application’s deployed architecture. The examples and budgets are
templates for a production assessment.

## Verification

The release archives 39 live Claude Code audits across the frontend and
security fixture studies. The evaluated frontend and performance profiles
identified the one-pass 180-row render in each of their final three audits.
The security follow-up produced explicit anonymous-denial
requirements in three of three updated audits. All six follow-up audits
identified missing `nosniff` on the complete local asset response and
kept all 11 scored release holds in place.
