# Laravel Guild 9.11.0

Claude 5.5 Models and Agent Fixes

## What’s new

- The solution architect, security engineer, tech lead, and performance
  engineer now use Claude Opus 5.5.
- Runtime budget estimates and eval reports include Opus, Sonnet, and Haiku
  5.5 pricing. Eval reports account for model-specific cache-read prices
  and Haiku 5.5's prompt-length tiers.

## Breaking changes

None.

## Fixes

- The performance agent preserves the existing sort column when recommending
  an Eloquent one-of-many relation. It calls out tie-breaking and checks rows
  whose timestamps and IDs sort differently.
- The QA agent checks the application's guest routing before asserting a
  redirect. When a fixture lacks a login route and uses Laravel's default
  JSON response for guests, it checks HTTP 401 and verifies the database row
  stayed unchanged. It separately tests HTTP 403 for an authenticated
  non-owner.

## Compatibility

- Use Claude Code 2.1.293 or later for all three Claude 5.5 models.
  The `sonnet` and `haiku` aliases follow the provider and session settings.
  [Claude Code model configuration](https://code.claude.com/docs/en/model-config)
- Gemini CLI uses its session model with the updated performance and QA
  instructions.

## Verification

The initial live comparison ran four pairs sequentially on the same Laravel
fixtures and task briefs. The updated models scored **22/24 vs. 21/24**,
used **20.2% less in CLI-reported cost**, and finished in **33.5% less wall
time** across the four cases.

| Laravel task | Model update | Quality | CLI usage cost | Wall time |
| --- | --- | ---: | ---: | ---: |
| Performance diagnosis | Opus 4.8 → 5.5 | 5/6 → 5/6 | $0.2481 → $0.1989 | 62.3 s → 45.2 s |
| Authorization review | Opus 5 → 5.5 | 6/6 → 6/6 | $0.7090 → $0.7171 | 262.2 s → 242.0 s |
| Pest feature tests | Sonnet 5 → 5.5 | 6/6 → 5/6 | $0.2851 → $0.1036 | 144.4 s → 30.7 s |
| Team ledger hygiene | Haiku 4.5 → 5.5 | 4/6 → 6/6 | $0.0404 → $0.0036 | 38.6 s → 19.7 s |

After the prompt fixes, both reruns scored **6/6** with the same model,
effort, fixture, and brief.

| Prompt rerun | Quality | CLI usage cost | Wall time |
| --- | ---: | ---: | ---: |
| Performance with Opus 5.5 | 5/6 → 6/6 | $0.1989 → $0.2033 | 45.2 s → 59.1 s |
| QA with Sonnet 5.5 | 5/6 → 6/6 | $0.1036 → $0.1048 | 30.7 s → 37.8 s |

- Laravel selected the correct newest comment when timestamp and ID order
  disagreed. For three posts, the recommended relation reduced the data
  query count from seven to three.
- The generated guest test passed with HTTP 401 and unchanged state in the
  original fixture, which has no login route. Six tests exposed the planted
  authorization and validation gaps. All 13 passed in the corrected control.
- All 533 local guardrail checks passed.

Each model and prompt result is one observation on these fixtures. Cost is
the CLI's reported usage value.
