# Laravel Guild 9.9.0

Agent Economics & Cost Optimization

## What’s new

- A deterministic economics router assigns economy, standard, or premium
  project tiers from workload complexity, risk, context, approval, and budget
  evidence. See [How do agents spend less without lowering quality?](../agent-economics.md).
- Cache and batch eligibility are explicit: only large hash-stable prefixes may
  be reused, and only independent, same-authority, side-effect-free items may be
  batched.
- Source-bound comparison receipts require representative actual billed
  evidence before a cheaper agent configuration becomes the accepted default.

## Breaking changes

None. Existing agent selectors and deliveries remain valid. Teams adopting the
economics gate should record a representative baseline before changing the
accepted tier, context, cache, batch, or retry configuration.

## Fixes

- A lower request price can no longer claim a saving when failures increase the
  total billed cost per successful outcome.
- Protected-risk work requires approval even when its separate protected-action
  flag is incorrect.
- Candidate evidence with unchanged configuration, oversized batches, excess
  attempts, weakened criteria, or insufficient samples now fails closed.

## Compatibility

- The harness uses Python 3 standard-library modules only.
- Receipt, policy, workload, and evidence schemas start at version 1.
- `haiku`, `sonnet`, and `opus` remain project selectors; the policy does not
  depend on mutable provider price claims.
- No dependency, database schema, or application-runtime change is required.

## Verification

- 10 registered economics scenarios cover tier floors, approvals, budgets,
  stable-prefix cache eligibility, and safe batching.
- 24 focused tests cover routing, quality-gated cost decisions, hard ceilings,
  criteria integrity, receipt tampering, path safety, and CLI round trips.
- The required `agent economics` hosted-CI job validates policy, replays all
  scenarios, and runs the focused suite.
- The enforcement map now names 23 controls, and immutable publication requires
  24 named hosted-CI jobs for the exact release commit.
