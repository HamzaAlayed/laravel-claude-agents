# Laravel Guild 9.11.1

Stage-return Write compatibility

## What’s new

This patch lets current Claude Code Write calls save valid stage returns.

## Breaking changes

None.

## Fixes

The stage-return hook validates both Write payload formats under `tool_input`.

| Format | Path field | Body field |
| --- | --- | --- |
| Current Claude Code Write | `file_path` | `content` |
| Legacy Write | `path` | `contents` |

When both body fields are present, the hook validates `content`. An empty or
invalid `content` is blocked even if `contents` contains a valid stage
return. The `jq` and Python parsers apply the same rule.

## Compatibility

Edit still validates `new_string`. The Gemini and Codex packages include the
synced hook.

## Verification

All 536 guardrail checks passed with `jq` and with the Python fallback.
Regression checks cover valid and invalid current Writes, legacy Writes,
Edit, and conflicting body fields.
