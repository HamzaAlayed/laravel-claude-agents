# Laravel Guild 8.6.0

## What’s new

Project releases now pass through a versioned, fail-closed harness. A manual
GitHub workflow validates one immutable `main` commit, proves every required CI
job passed for that exact SHA, creates an annotated tag, publishes prepared
notes, and retains a machine-readable receipt.

- `config/release-harness.json` owns the release contract.
- `scripts/release.py validate` checks release artifacts locally.
- `scripts/release.py check` performs a read-only Git and GitHub preflight.
- `scripts/release.py publish` performs the gated, idempotent publication.
- The new `release automation` CI job tests the publisher and validates the
  current release artifacts.

See [Publish an immutable release](../release-automation.md) for the complete
procedure and recovery runbook.

## Breaking changes

Maintainers should no longer create release tags manually. Publication requires
the exact clean `origin/main` commit, synchronized version files, complete
release notes, and all named CI jobs passing for that SHA. A lightweight tag or
conflicting existing tag now blocks the release instead of being reused.

## Fixes

- Partial version bumps and missing changelog or release-note sections fail
  before any tag is created.
- Dirty worktrees, stale branch commits, failed jobs, incomplete jobs, and
  missing required jobs cannot publish.
- Git or GitHub inspection errors fail closed instead of being interpreted as
  “not found.”
- A tag created by a partially successful run is safely reused on an identical
  rerun; it is never replaced.

## Compatibility

This changes only the project-maintainer release path. Installed agent,
command, hook, console, Claude, Cursor, Gemini, and Codex runtime behavior is
unchanged. Stable versions remain SemVer `X.Y.Z` with annotated `vX.Y.Z` tags.

## Verification

- Twenty-three zero-dependency unit tests cover artifact drift, CI job gates,
  annotated-tag invariants, API failures, publication, and idempotent reruns.
- Guardrail ratchets bind CI and the manual workflow to the release harness,
  immutable checkout, receipt, and non-force policy.
- The standard shell, manifest, frontmatter, generator, budget, console,
  kernel, eval-parser, and UI gates run before publication.
- Version 8.6.0 is published through this new Release workflow itself, proving
  the hosted path end to end.
