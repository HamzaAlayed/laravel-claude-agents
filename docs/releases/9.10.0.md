# Laravel Guild 9.10.0

Research Intake & Evidence Review

## What’s new

- [Thirteen source-linked IBM AI agents notes](../research/ibm-ai-agents/README.md)
  cover the guide's eight introductory articles and five additional readable
  resource pages. An index identifies the other linked formats and forms.
- An [agent-pack review](../research/2026-09-28-ibm-agent-pack-review.md)
  maps each item to current Laravel Guild controls and records the first
  concrete improvement.
- The technical writer inventories every directly linked item on a named
  source hub, records its type and access status, and separates source claims
  from project recommendations.
- The solution architect compares cited ideas with existing controls before
  proposing a research-led change, requiring a reproducible gap and measurable
  success condition.

## Breaking changes

None. Agent names, selectors, tool grants, schemas, and delivery interfaces are
unchanged.

## Fixes

- Source-hub reading sets now have an explicit completeness check, addressing
  the missed resource pages in the initial IBM guide collection.
- Report landing pages are identified as such rather than treated as the full
  downloadable reports.

## Compatibility

- Existing Claude Code, Cursor, Gemini, and Codex consumers can use the same
  agent selectors and workflows.
- No dependency or application runtime changes are required.
- The IBM notes paraphrase the source pages and link to the originals; they do
  not contain full-text copies.
