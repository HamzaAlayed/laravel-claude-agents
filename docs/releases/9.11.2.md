# Laravel Guild 9.11.2

Close, sprint, and lessons Write compatibility

## What’s new

Claude Code can now save valid close, sprint, and lessons files using its
current Write payload.

## Breaking changes

None.

## Fixes

The hooks for `docs/delivery/*/close.md`, `docs/sprints/*/sprint.md`, and
`docs/team/lessons.md` accept both Write formats under `tool_input`.

| Format | Path field | Body field |
| --- | --- | --- |
| Current Claude Code Write | `file_path` | `content` |
| Legacy Write | `path` | `contents` |

When both body fields are present, both parsers validate `content`. An empty
or invalid `content` is blocked even if the legacy `contents` is valid.

## Compatibility

Edit calls continue to use `new_string`. The Gemini and Codex packages
include the same updated hooks.
