# Laravel Guild 8.9.0

## What’s new

Every persisted delivery mutation now produces a typed, correlated event in a
versioned observability ledger. Operators can verify one delivery without
reading raw conversations or guessing from generated status prose.

- `kernel.json` stores the authoritative monotonic event chain.
- `events.jsonl` provides a machine-readable derived trail.
- `observability.md` summarizes event counts, usage, and current stage status.
- `guild observe verify`, `list`, and `repair` inspect integrity and safely
  regenerate derived views.
- A separate required `observability contract` CI job prevents schema,
  redaction, CLI, or integrity behavior from drifting before publication.

See [delivery observability](../observability.md) for the event contract,
commands, limits, and recovery runbook.

## Breaking changes

None. Existing delivery state loads without fabricated history. Its first
persisted mutation under v8.9.0 starts a new trace at sequence 1.

## Fixes

- Delivery lifecycle evidence is no longer split across unrelated generated
  views with no common correlation contract.
- Missing, reordered, modified, or stale derived events now produce an explicit
  unhealthy result instead of looking current.
- A damaged authoritative chain cannot silently grow through a subsequent
  state save.
- Raw prompts, tool inputs, report bodies, and secret values are excluded from
  delivery observability events.

## Compatibility

Claude, Cursor, Codex, Gemini, and classic installs keep the same lifecycle
commands. `kernel.json` gains `observability_events`; older state remains
readable. Traces grow with persisted kernel mutations and remain bounded by the
existing delivery tool-call and retry budgets.

The hash chain is an integrity mechanism, not a signature against arbitrary
same-account code execution. Console JSONL remains a separate bounded
diagnostic stream and is not promoted to authority.

## Verification

- Ten independent observability tests cover schema parity, correlated event
  order, hash chaining, redaction, legacy migration, CLI behavior, derived-view
  repair, and authoritative-state tamper detection.
- The existing 209 kernel tests pass with event emission enabled.
- The canonical orchestration contract requires `observe verify` on resume and
  before closure.
- GitHub-hosted CI requires the observability job for the exact release commit.
