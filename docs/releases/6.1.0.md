# Laravel Guild 6.1.0

## What’s new

Path ownership now acts before a planned agent writes, not only when it reports
completion. On Claude Code, the new registry-backed policy checks every native
`Write`, `Edit`, and `NotebookEdit` call against the active kernel delivery.

- A queued stage must be claimed before it can edit.
- One running stage may edit its owned path and files nested beneath it.
- Two running stages for the same agent are treated as ambiguous and blocked.
- Read-only agents are denied native write tools from their shared harness
  profile, even if tool configuration drifts.
- Documentation-only agents may write only the documentation roots declared by
  the shared harness, including on the direct fast path.
- Paths that leave the project directly or through a symlink are blocked.

Direct single-specialist work remains available when no active delivery
contains that agent. Task-owned agents remain project-bound, while docs-only
agents remain documentation-bound. Main-thread writes and agents from other
plugins are not governed by this Guild-specific policy.

## Breaking changes

None. Correctly claimed v6 plans already carry the ownership data consumed by
the new hook. Existing direct point-work remains the fast path.

## Compatibility

The path hook is Claude Code-specific because that hook payload identifies the
calling subagent. Gemini keeps its agent tool allowlists, and Codex Core does
not ship the Guild subagent team.

The new boundary covers native file-write tools. Bash commands continue through
the existing production, credential, helper-file, Sail, and read-only-reviewer
guards; this release does not claim general shell sandboxing.

## Verification

- Guardrail cases cover queued, running, completed, ambiguous, malformed, and
  direct-fast-path states.
- Path cases cover exact ownership, nested files, sibling paths, project
  escape, missing paths, and symlink escape.
- Hook synchronization, installer idempotency, manifests, generated targets,
  inventory claims, and all existing release suites remain required gates.
