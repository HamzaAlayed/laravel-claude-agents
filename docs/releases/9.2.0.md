# Laravel Guild 9.2.0

## What’s new

Laravel Guild can now create the captures its outcome benchmark requires. The
new Composer package auto-discovers a Laravel service provider and registers
`php artisan guild:benchmark-capture` for typed, application-owned HTTP,
command, job, and Livewire scenarios.

- At least two warmups and seven measured runs are enforced.
- Every measured run records query count and latency plus response, database,
  event, and job fingerprints.
- Captures already match the v9.1 comparator schema and remain below the
  delivery artifact directory.
- A dedicated Laravel/Testbench/Pest job is required for publication.

See the [capture adapter runbook](../benchmark-capture.md) for installation,
scenario examples, trust boundaries, and failure recovery.

## Breaking changes

There are no breaking changes to existing agent, kernel, comparator, or
installation workflows. Applications opt into the Composer package when they
need Laravel-native capture production.

The package requires PHP 8.3 or newer and supports Illuminate/Laravel 11, 12,
and 13. The release test matrix exercises Laravel 13.

## Fixes

- Application teams no longer have to reverse-engineer the capture JSON
  contract or build ad hoc query counters.
- DML, DDL, ambiguous CTEs, multiple statements, locking reads, export clauses,
  PRAGMA statements, and `EXPLAIN ANALYZE` fail closed.
- A changed database fingerprint or unstable observable fingerprint prevents
  output even when the measured code appears faster.
- Absolute paths, traversal, output outside `docs/delivery`, and symlinked
  output parents are rejected.

## Compatibility

Claude, Cursor, Codex, Gemini, and classic agent installs retain the v9 delivery
lifecycle. The Composer package is separate and uses Laravel package discovery;
installing the agent pack alone does not add PHP dependencies to a consumer
application.

Capture is allowed in `local` and `testing`. Dedicated staging requires both
`dedicatedTarget: true` and `--allow-staging`. Production and unknown
environments are denied. A database-side read-only credential and faked
external services remain operator responsibilities.

## Verification

- Pest exercises command discovery, a real SQLite read, comparator-compatible
  output, payload exclusion, pre-execution write blocking, environment policy,
  path containment, strict schema validation, canonical hashing, and SQL
  bypass attempts without migrations.
- Composer validation and the pinned lock file make the hosted Laravel 13 test
  environment reproducible.
- The enforcement map publishes 16 controls, including the adapter's runtime,
  CI, operator, prompt, and trust boundaries.
- Immutable release publication requires all 17 named hosted jobs for the
  exact v9.2.0 commit.
