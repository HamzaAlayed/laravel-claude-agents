## Screenshot / GIF capture recipe

No `png`/`gif` is committed in this repo today. Run 7's live GIF was never checked in. There is no separate screenshot harness — actor poses live in `console-ui/src/lib/actorPose.ts`; the console is `console-ui/` (Vite) served by `scripts/console/serve.py`.

**Do not invent images.** If a live capture is not possible in the current environment, ship the docs with a one-line pending note and use this recipe later. The GIF does not block the rest of Adoption.

### Preferred — live `/console` mid-run board

From a Laravel app that already has the plugin (or this pack loaded as a local plugin):

```bash
# In Claude Code, from the Laravel project root:
/console
```

1. The command starts `python3 scripts/console/serve.py --port 8378` (port increments if busy). First run creates `.claude/console/venv` and installs `claude-agent-sdk`.
2. Open the tokenized URL it prints (`http://127.0.0.1:<port>/?token=…`). A URL without the token will not work (`commands/console.md`).
3. Kind = Command, Target = `make-feature`, text e.g. `Donation --api`. Click **Run**.
4. Wait until **at least two specialist cards** are on the board (a single lane is Focus mode, not the pipeline board — `console-ui/src/App.test.tsx`). Mid-run = `▶` cards live, actors posed `working` / `thinking` / `needs`.
5. Save the still:

   ```bash
   # from this pack repo, after the window is frontmost
   mkdir -p docs/images
   screencapture -l$(osascript -e 'tell application "Google Chrome" to id of window 1') \
     docs/images/console-board-mid-run.png
   ```

   Or macOS **Cmd-Shift-4**, then move the file to `docs/images/console-board-mid-run.png`.
6. Record a short live-run GIF (CleanShot / Kap / QuickTime → ffmpeg) to `docs/images/console-live-run.gif`.
7. Replace the pending notes in `README.md` and `docs/onboarding.md` with image tags pointing at those two files (paths from the repo root: `docs/images/console-board-mid-run.png` and `docs/images/console-live-run.gif`).

Optional rider: the six CAN-RIDE items in `docs/plans/2026-08-04-console-motion-followups.md` may ride if this session already has the console open. None of them blocks 1.43.0.

### Acceptable fallback — fakeServer in a real browser

`console-ui` tests drive a mid-run board through `installFakeServer` (`console-ui/src/test/fakeServer.ts`). jsdom produces no pixels. To capture the same events in Chrome / Playwright:

1. `cd console-ui && npm ci`
2. Mount `App` with `launch()` from `App.test.tsx`, emit two `agent_start` events (Adam + Dina) plus a parked approval, dismiss the sheet.
3. Screenshot the board (not the modal sheet) to `docs/images/console-board-mid-run.png`.
4. Caption it as a fixture-driven console capture, not a billed live run.
